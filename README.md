# RxNext

A production-ready Next.js foundation connected to GitHub and Vercel.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Vercel
